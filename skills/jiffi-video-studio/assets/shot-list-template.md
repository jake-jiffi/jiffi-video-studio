| ID / sequence | Purpose | Planned duration | Source route / file | Subject and action | Camera or graphic state | References / selected board panel | Sound / graphics | Required visible result |
|---|---|---|---|---|---|---|---|---|

Routes: supplied footage, capture, generated shot or graphics. Planning method
is separate: edit list, image board, timed animatic or 3D only where useful.
Keep IDs stable; add S05a and S05b if a shot is split later. Source clip limits
are not universal shot durations. Longer programmes can group IDs by sequence.

For connected shots, link the relevant scene plan. Record camera side, eyeline,
entering and leaving object/subject state and cut relationships where relevant.
An abstract animation or UI demonstration needs only the state checks that
apply to it. Record important action-result evidence and any uncertain motion
that should be piloted before paying for dependent shots.

For performing characters, note intention, attention and reactions, including
listeners. Separate required marks/contact from the acting the model may add.
Link the performance section of the scene plan or keep brief notes here for
a standalone shot. A static camera or fixed mark does not require a frozen pose.

If using board frames for generation, record each clean frame's file/version
and actual model field or reference role. A planning-only panel is not a
submitted generation input.

For audible shots, link the sound plan or brief: stable voice identity,
performance/effort, listening perspective, acoustic setting, ambience and timed
effects. Note changes that should carry across the cut. A new camera framing
does not by itself require a different voice distance or room treatment.
